# 学伴

把今天学的，变成明天记得住的。

学伴将课程笔记、文章和课堂记录整理成学习笔记、知识结构、必要拓展与测验题，帮助你建立从输入到理解、再到练习的学习闭环。

## 在线体验

[打开学伴落地页](https://1335273652-glitch.github.io/learning-assistant-landing/)

## 学伴 Skill

[查看学伴 Skill 仓库](https://github.com/1335273652-glitch/xueban) · [阅读 SKILL.md](https://github.com/1335273652-glitch/xueban/blob/main/SKILL.md)

Skill 可将提供的学习材料整理为：

- 学习笔记与核心概念
- 知识结构与概念关系
- 帮助理解和应用的拓展内容
- 回忆、理解和应用测验题，以及答案解析

## 项目说明

本仓库是学伴的静态介绍页面，包含产品介绍和学习成果示例。页面中的内容为展示示例；当前落地页不提供材料上传或自动生成服务。

## 本地查看与更新

直接用浏览器打开 `index.html` 即可查看页面。

修改页面后，将更新提交到本仓库的 `main` 分支，GitHub Pages 会自动部署。
